# 🎮 Alber.games — Sala de Juegos

Este es el repositorio de mi portal de minijuegos y experimentos web, desarrollado como un laboratorio creativo con experiencias interactivas ligeras y adictivas.

> 🔗 **Visita la web aquí:** [albersoftworks.github.io/alber.games](https://albersoftworks.github.io/alber.games/)

## 📄 Descripción

Mi página de juegos está diseñada para:

- **Alojar** una colección propia de juegos interactivos (*Bubble Clicker, Tech Startup, Hop Hop y más en camino*) listos para jugar en el navegador sin instalaciones.
- **Experimentar** con físicas, detección de colisiones, persistencia de datos local y sistemas de audio nativos.
- **Servir** como complemento lúdico a mi perfil principal como desarrollador.

La web está construida exclusivamente con HTML5, CSS3 y JavaScript, huyendo de motores gráficos pesados para garantizar una carga instantánea y un rendimiento óptimo ejecutado 100% en el lado del cliente.

## 🛠️ Tecnologías utilizadas

- **HTML5 & API Canvas:** Para la estructuración semántica de la web y el renderizado fotograma a fotograma de los juegos de plataformas.
- **CSS3:** Para la maquetación responsive, diseño de interfaz UI/UX con efectos de cristal esmerilado y animaciones nativas por *keyframes*.
- **JavaScript (Vanilla):** Para la lógica de los juegos incrementales, bucles de animación, física de gravedad y eventos de interacción.
- **Web Audio API:** Para la síntesis y generación dinámica de efectos de sonido mediante osciladores.
- **LocalStorage:** Para guardar de forma segura los récords y el progreso de los jugadores en su propio navegador.
- **GitHub Pages:** Para el despliegue continuo y alojamiento del proyecto estático.
